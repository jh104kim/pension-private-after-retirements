# 🏦 은퇴 연금 분석 웹앱

> **1973년생 개인 사용자의 은퇴 후 연금 수령 전략 분석 도구**  
> 9개 연금 상품의 나이별 월 수령액을 시각화하고, 절세 시나리오·건강보험료 시뮬레이션을 제공하는 개인용 MVP 웹앱

---

## 주요 기능

| 탭 | 기능 |
|----|------|
| **현금흐름** | 55~90세 연령별 누적 바 차트 — 연금·임대소득·세금·건보료 통합 시각화 |
| **연금 현황** | 9개 상품 목록·65세 수령액 도넛 차트·수령 기간 타임라인 |
| **절세 시나리오** | 현재/분산/지연/최적 조합 4가지 비교 — 세금·건보료 포함 세후 수령액 비교 |
| **건강보험** | 임대소득·부동산 슬라이더로 건보료 실시간 추정·피부양자 자격 판정 |
| **은퇴 소득** | 임대·근로·금융·기타소득 입력 → 종합과세 리스크 체크리스트 자동 판정 |

> ⚠️ **세금·건강보험료 수치는 추정값입니다.** 국세청·국민건강보험공단 확인이 필요합니다.

---

## 스크린샷

### 현금흐름 대시보드
55~90세 연령별 수령액 구성을 누적 막대 차트로 단일 뷰포트에 표시합니다.

### 절세 시나리오
IRP 분산 수령·국민연금 지연 수령 조합에 따른 세금·건보료 절감 효과를 비교합니다.

### 건강보험 시뮬레이터
슬라이더로 임대소득과 부동산 시가를 조정하면 건보료가 실시간 재계산됩니다.


## Cloudflare 배포 및 AI 챗봇

이 MVP의 AI 챗봇은 화면 오른쪽 고정 패널로 제공되며, 프론트엔드는 `/api/chat`만 호출합니다. Cloudflare API Token은 브라우저에 노출하지 않고 `functions/api/chat.js`의 Pages Function에서 Workers AI REST API를 호출합니다.

### Cloudflare Pages 설정

| 항목 | 값 |
|------|-----|
| Build command | `npm run build` |
| Build output directory | `dist` |
| Functions directory | `functions` |
| Local chatbot URL | `http://localhost:8788` (`npm run dev:pages`) |

### 환경변수

Cloudflare Pages 프로젝트 환경변수 또는 로컬 `.env`에 아래 값을 설정합니다.

```bash
CLOUDFLARE_ACCOUNT_ID=
CLOUDFLARE_API_TOKEN=
CLOUDFLARE_AI_MODEL=@cf/meta/llama-3.1-8b-instruct
```

> `VITE_` 접두사 환경변수는 브라우저 번들에 노출될 수 있으므로 실제 배포에서는 사용하지 않는 것을 권장합니다.

## 데이터 기준

| 인덱스Up | 삼성생명 | 65~90세 | 비과세 |
| 우리아이 1 | 삼성생명 | 60~90세 | 자녀 양도 예정 |
| 스마트Top | 삼성생명 | 65~90세 | 비과세 |
| 우리아이 2 | 삼성생명 | 60~90세 | 자녀 양도 예정 |
| 연금저축골드 | 삼성생명 | 56~90세 | 세제적격 |

### 사용자 기본값

| 항목 | 값 |
|------|-----|
| 은퇴 예정 | 2030년 (57세) |
| 국민연금 개시 | 2038년 (65세) |
| DB퇴직연금 잔액 | 3.9억원 |
| IRP 잔액 | 6천만원 |
| 연금저축 잔액 | 6천만원 |
| 부동산 시가 | 26억원 |
| 임대소득 | 월 300만원 |

### 계산 기준 요약

- **연금소득세**: 수령 나이별 분리과세 3.3~5.5% (사적연금 연 1,200만원 이하 기준)
- **종합소득세**: 연금소득공제 후 누진세율 6~45%
- **건강보험료**: 소득·재산점수 합산 × 208.4원/점 (2024 지역가입자 기준) *(추정)*
- **IRP 분산 수령** (spread): 57~64세 연 9,620천원 균등 인출
- **국민연금 지연** (delayed): 65~69세 미수령 → 70세 이후 수령액 × 1.36

## 주의사항

- 이 앱의 **세금·건강보험료 계산 결과는 모두 추정값**입니다.
- 실제 납세액은 **국세청 홈택스**, 건보료는 **국민건강보험공단**을 통해 확인하세요.
- 국민연금 수령액은 공단 조회 기반 하드코딩 값이며, 실제 수령액과 다를 수 있습니다.
- 개인 재정 정보가 포함된 저장소입니다. **Private 저장소로 유지**하세요.
