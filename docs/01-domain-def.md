| 근로소득 (보너스) | **5천만원** | 35~38% | — | 2030년 종료 |

| 임대소득 | 3,600만원 | 종합과세 합산 | — | 현재도 수령 중 가능 |

## 5. 세금 계산 도메인

### 5-1. 사적연금 소득세 (세제적격: 연금저축·IRP)

| 수령 나이 | 세율 (지방세 포함) |
|------|------|
| 55세 ~ 69세 | **5.5%** |
| 70세 ~ 79세 | **4.4%** |
| 80세 이상 | **3.3%** |

- 연간 사적연금 수령액 **1,200만원 이하** → 위 세율로 분리과세
- 연간 사적연금 수령액 **1,200만원 초과** → 종합과세 or **15% 분리과세** 선택

### 5-2. 공적연금 소득세 (국민연금)

- 연금소득공제 적용 후 종합소득세율로 과세
- 연금소득공제 (2024년 기준):

| 총 연금액 | 공제액 |
|------|------|
| 350만원 이하 | 전액 공제 |
| 350만원 초과 ~ 700만원 | 350 + 초과분 × 40% |
| 700만원 초과 ~ 1,400만원 | 490 + 초과분 × 20% |
| 1,400만원 초과 | 630 + 초과분 × 10% (한도 900만원) |

### 5-3. DB 퇴직연금 소득세

- 퇴직소득세 산식 적용 (근속연수 공제)
- 연금 수령 시: 퇴직소득세의 70% (10년 초과 시 60%)

### 5-4. 세제비적격 상품 (변액연금·노후적립)

- 10년 이상 유지 + 55세 이후 수령 → **보험차익 비과세**
- 해당 사용자 상품 모두 가입 후 20년 이상 경과 → 비과세 적용

### 5-5. 종합소득세율 (2024년 기준)

| 과세표준 | 세율 | 누진공제 |
|------|------|------|
| 1,400만원 이하 | 6% | — |
| 1,400만원 ~ 5,000만원 | 15% | 126만원 |
| 5,000만원 ~ 8,800만원 | 24% | 576만원 |
| 8,800만원 ~ 1.5억원 | 35% | 1,544만원 |
| 1.5억원 ~ 3억원 | 38% | 1,994만원 |
| 3억원 ~ 5억원 | 40% | 2,594만원 |
| 5억원 초과 | 42% | 3,594만원 |
| 10억원 초과 | 45% | 6,594만원 |

## 6. 건강보험 도메인

### 6-1. 지역가입자 보험료 산정

- **보험료 = (소득점수 + 재산점수) × 점수당 단가 (208.4원, 2024년)**
- 장기요양보험료 = 건강보험료 × 12.95%

**소득 반영 항목:**
- 연금소득 (공적 + 사적, 필요시 공제 적용)
- 임대소득 (필요경비 60% 공제 후)
- 금융소득 (이자·배당 합산)
- 근로소득

**재산 반영 항목:**
- 부동산 과세표준 (공시가격 기준)
- 금융재산 (500만원 초과분)
- 자동차

### 6-2. 피부양자 자격 상실 조건

| 구분 | 기준 | 비고 |
|------|------|------|
| 소득 기준 | 연간 소득 합계 **2,000만원 초과** | 모든 소득 합산 |
| 재산 기준 A | 재산세 과세표준 **9억원 초과** | 즉시 탈락 |
| 재산 기준 B | 재산세 과세표준 **5.4억~9억** + 연소득 **1,000만원 초과** | 동시 충족 시 탈락 |

> **⚠️ 해당 사용자 리스크:** 부동산 26억원 보유 → 재산세 과세표준이 9억 초과 가능성 높음  
> → 은퇴 시점(2030년)부터 지역가입자 전환 가능성 매우 높음  
> → 소득 공백 구간(2030~2038)에도 재산 기준만으로 지역가입자 보험료 부과 예상
