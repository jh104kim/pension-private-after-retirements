# 제품 요구사항 문서 (PRD)

> **은퇴 연금 분석 웹앱 MVP — 구현 완료 기준 정리**
> 작성 기준: 2026년 06월 (구현 완료 시점)
> 이 문서는 사전 기획서가 아닌 **현재 구현된 기능의 요구사항 명세**다.

---

## 1. 제품 개요

1973년생 사용자(2030년 57세 은퇴 예정)의 **은퇴 후 연금 수령 전략 분석**을 목적으로 하는 개인용 웹앱 MVP.

| 항목 | 내용 |
|------|------|
| 대상 사용자 | 1인 (1973년 05월생, 2030년 57세 은퇴 예정) |
| 분석 기간 | 55세 ~ 90세 (36개 연령 포인트) |
| 연금 상품 수 | 9개 (공적연금 1 + 세제적격 2 + 세제비적격 6) |
| 기술 스택 | Vite 6 + React 18 + Tailwind CSS 3 + shadcn/ui + Recharts |
| AI 챗봇 | Cloudflare Pages Functions + Workers AI (`/api/chat`) |
| 뷰포트 | 1440 × 900 고정 (No Scroll) |
| 세금·건보료 | **추정값** (국세청·건보공단 2024년 기준 근사치, 확정값 아님) |

---

## 2. 사용자 문제

| # | 문제 | 현재 해결 여부 |
|---|------|------|
| 1 | 9개 연금 상품을 나이별로 통합 조망하는 수단이 없다 | ✅ CashFlowDashboard + PensionInput |
| 2 | 임대소득이 건강보험 피부양자 자격과 보험료에 미치는 영향을 직관적으로 알기 어렵다 | ✅ HealthInsurance |
| 3 | IRP 분산 수령·국민연금 지연 수령 등 절세 시나리오의 효과를 수치로 비교할 수단이 없다 | ✅ TaxScenario |
| 4 | 세금·건보료를 포함한 세후 실수령액을 나이별로 한눈에 볼 수 없다 | ✅ CashFlowDashboard |
| 5 | 임대소득·금융소득 규모가 종합과세 기준을 초과하는지 즉시 판단하기 어렵다 | ✅ IncomeInput |
| 6 | 앱 계산 결과를 자연어로 해석하고 리스크를 질문하기 어렵다 | ✅ ChatPanel + Cloudflare Workers AI |

## 3. MVP 목표

1. **통합 시각화** — 9개 연금 상품을 55~90세 연령별 누적 막대 차트로 단일 뷰포트에 표시
2. **절세 시나리오 비교** — 현재 계획 / 분산 수령 / 지연 수령 / 최적 조합 4개 시나리오를 세금·건보료 포함 비교
3. **건보료 시뮬레이터** — 임대소득·부동산 슬라이더로 건강보험료 실시간 추정
4. **소득 리스크 판정** — 사적연금 1,200만원·임대소득 2,000만원·금융소득 2,000만원 기준 초과 여부 자동 표시
5. **단일 뷰포트 완결** — 5개 탭 전체가 스크롤 없이 1440×900 내에서 완결
6. **AI 해석 보조** — 현재 앱 컨텍스트를 기반으로 연금·세금·건보료 리스크를 추정 설명하는 오른쪽 챗봇 제공

## 5. 화면별 기능 요약

### 5-1. 현금흐름 대시보드 (`CashFlowDashboard`)

**목적**: 55~90세 전 구간 현금흐름을 한눈에 파악하는 메인 시각화

| 기능 | 내용 |
|------|------|
| 누적 막대 차트 | 국민연금·DB퇴직·IRP·연금저축·세제비적격·임대소득 스택, 세금·건보료 음수 스택 |
| 나이별 데이터 테이블 | 총 수령·세금·건보료·순수령 36행 (추정) |
| 주요 이벤트 마커 | 57세 은퇴·61세 DB개시·65세 국민연금개시 등 |
| KPI 카드 | 총 적립금·65세 세전 월수령·65세 세후 월수령·순 총 수령 합계 |
| 추정 라벨 | 세금·건보료 수치 전체 "추정" 표기 |

### 5-2. 연금 현황 (`PensionInput`)

**목적**: 9개 연금 상품 구성 및 수령 기간 파악

| 기능 | 내용 |
|------|------|
| 상품 목록 테이블 | 기관·상품명·65세 월수령·수령기간·세제구분 (10행 — IRP 미결정 포함) |
| 수령액 구성 도넛 차트 | 65세 기준, 중앙에 연금 합계 표시 |
| 수령 시작 타임라인 | 55~90세 간트 형식, 상품별 수령 구간 시각화 |
| KPI 카드 | 총 적립금 (세제적격)·65세 월수령·세제적격 3개·세제비적격 6개 |

### 5-3. 절세 시나리오 (`TaxScenario`)

**목적**: 수령 방법 변경 시 세금·건보료 절감 효과 비교

| 기능 | 내용 |
|------|------|
| 4개 시나리오 토글 | 현재 계획 / 분산 수령 / 지연 수령 / 최적 조합 (네이티브 버튼, 다중 선택) |
| 65세 기준 비교 바 차트 | 소득세·건보료·사적연금세·DB세 스택 비교 |
| 55~90세 라인 차트 | 시나리오별 세후 월수령액 추이 비교 (토글 연동) |
| 절세 전략 테이블 | 6개 전략 (IRP 분산·국민연금 지연·세금 종류·임계점·효과) |
| 추천 카드 | 분산+지연 수령 / 현재 계획 유지 2개 |
| 추정 라벨 | 모든 수치 "추정" 표기 |

**시나리오 정의**:

| ID | 이름 | 핵심 변경 |
|----|------|------|
| `current` | 현재 계획 | 변경 없음 |
| `spread` | 분산 수령 | IRP 57~64세 연 9,620천원 분산 인출 |
| `delayed` | 지연 수령 | 국민연금 65~69세 미수령 → 70세 이후 ×1.36 |
| `optimal` | 최적 조합 | IRP 분산 + 국민연금 지연 동시 적용 |

### 5-4. 건강보험 (`HealthInsurance`)

**목적**: 임대소득·부동산 규모에 따른 건강보험료 추정 및 피부양자 자격 판정

| 기능 | 내용 |
|------|------|
| 임대소득 슬라이더 | 0 ~ 7,200만원/년 (기본값 3,600만원) |
| 부동산 시가 슬라이더 | 0 ~ 50억원 (기본값 26억원) |
| 보험료 실시간 계산 | 소득보험료·재산보험료·장기요양보험료·합계 (추정, 만원/월) |
| 기준 요약 배너 | 재산세 과표·재산점수·소득점수·산출 공식 |
| 피부양자 판정표 | 소득 기준·재산 기준·현재 판정 상태 표시 |
| 나이별 추이 차트 | 57~80세 건보료 바 차트 (국민연금 개시 전후 변화 포함) |
| 절감 시나리오 4종 | 현재 계획·임대 경비 42.6%·부동산 50% 매각·배우자 직장 피부양 |
| 추정 라벨 | 전 수치 "추정" / "공단 확인 필요" 표기 |

**기본값 추정 건보료** (57세 기준, 슬라이더 기본값):
- 소득보험료 + 재산보험료 합산 ≈ **약 27만원/월** *(추정 — 건보공단 확인 필요)*

### 5-5. 은퇴 소득 (`IncomeInput`)

**목적**: 연금 외 소득 입력 및 종합과세 리스크 판정

| 기능 | 내용 |
|------|------|
| 소득 입력 필드 4개 | 임대소득 (만원/월) · 근로소득 (만원/월) · 금융소득 (만원/년) · 기타소득 (만원/년) |
| 컨텍스트 실시간 반영 | 입력 변경 → PensionContext → 전 탭 연동 |
| KPI 카드 | 65세 총 월 소득·연금수령액·기타소득·종합과세 판단 |
| 소득 구성 가로 바 차트 | 7개 마일스톤(57·60·61·65·70·75·80세) × 연금·임대·기타소득 스택 |
| 리스크 체크리스트 | 4항목 동적 판정 (임계값 초과 시 상태 변경) |
| 추정 라벨 | "추정"/"확인 필요" 전 항목 병기 |

**리스크 체크 항목**:

| 항목 | 임계값 | 초과 시 |
|------|------|------|
| 사적연금 1,200만원 분기점 | 연 1,200만원 | ⚠ IRP 합산 확인 필요 |
| 임대소득 종합과세 | 연 2,000만원 | ⚠ 종합과세 의무 |
| 피부양자 자격 탈락 | 소득 연 2,000만원 | ❌ 지역가입자 전환 확정 |
| 금융소득 2,000만원 | 연 2,000만원 | ⚠ 금융소득 종합과세 |

### 5-6. AI 챗봇 (`ChatPanel`)

**목적**: 현재 앱의 연금·소득·자산·건보료 추정 결과를 자연어로 설명하고, 사용자의 질문에 추정 기반 답변 제공

| 기능 | 내용 |
|------|------|
| 오른쪽 고정 패널 | 탭 화면을 가리지 않는 우측 overlay, 기본은 하단 버튼으로 접힘 |
| 앱 컨텍스트 전달 | `PensionContext`의 소득·자산·현금흐름·건보료 요약을 AI에 전달 |
| Cloudflare Workers AI | Pages Function `/api/chat`에서 Workers AI REST API 호출 |
| 보안 구조 | API Token은 브라우저에 노출하지 않고 Function 환경변수에서 사용 |
| 빠른 질문 | 65세 이후 리스크·피부양자 탈락·절세 우선순위 질문 제공 |
| 안전 문구 | 세금·건보료는 추정, 확정 판단은 세무사·국민건강보험공단 확인 필요 |

## 7. 계산 로직 요약

> **모든 계산 결과는 추정값이며 국세청·건보공단 확인이 필요하다.**

### 7-1. 연금소득세 (세제적격)

- 연금 수령 나이별 분리과세율: 55~69세 5.5% / 70~79세 4.4% / 80세~ 3.3%
- 사적연금 합산 연 1,200만원 이하: 분리과세 선택 가능
- 1,200만원 초과: 종합과세 전환

### 7-2. 종합소득세 (국민연금·임대소득 등)

- 연금소득공제 적용 후 누진세율 (6~45%)
- 임대소득: 단순경비율 42.6% 적용 시 과세소득 = 총수입 × 0.574 *(추정)*

### 7-3. DB 퇴직소득세

- `dbRetirementTax(390_000, 30, 20)` — 잔액 3.9억·근속 30년·수령 20년 기준
- 분리과세 (종합과세 합산 없음)

### 7-4. 지역가입자 건강보험료

- 소득점수 + 재산점수 합산 × 208.4원/점 (2024 기준) *(추정)*
- 소득 기준: 연간 과세소득 (임대소득 과세분 + 연금소득 과세분)
- 재산 기준: 부동산 시가 × 60% (공시가) × 60% (재산세 과표)
- 장기요양보험료: 건강보험료 × 12.95%
- 기본 추정치: 임대소득 연 3,600만원 + 부동산 26억 기준 **약 27만원/월** *(추정)*
- **확정값은 국민건강보험공단 직접 확인 필요**

### 7-5. IRP 분산 수령 (spread / optimal 시나리오)

- 57 ~ 64세 (8년): 연 9,620천원 균등 인출
- 사적연금 연간 합산 1,200만원 이하 유지 → 분리과세 5.5% 적용

### 7-6. 국민연금 지연 수령 (delayed / optimal 시나리오)

- 65 ~ 69세: 수령액 0원
- 70세 이후: 정상 수령액 × 1.36 (36% 증액) *(추정, 실제 가산율은 공단 기준 확인)*

### 7-7. AI 챗봇 호출

- 프론트엔드: `sendChatMessage(message, context)` → `/api/chat`
- 서버 프록시: `functions/api/chat.js`
- 모델 기본값: `@cf/meta/llama-3.1-8b-instruct`
- 환경변수: `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_AI_MODEL`
- 응답 원칙: 앱 컨텍스트 숫자 우선, 컨텍스트 밖 세율·절감액·자격 판단은 "확인 필요"로 안내
- 실패 메시지: `AI 응답 생성에 실패했습니다. API 키와 모델명을 확인하세요.`
