# 데이터 명세서 (Data Specification)

> `pensionData.js` 배열 검증 기준표 — 엑셀 원본 대조용  
> 출처: `연금수령.xlsx` → 시트 `통합연금포탈_예시연금액`  
> 단위: **천원/년 (연간)**

---

## 1. 엑셀 → JS 변수 매핑

| 엑셀 행 | 기관 | 상품명 (엑셀 원문) | JS 키 | 수령 기간 | 소 계 |
|------|------|------|------|------|------|
| 2 | 국민연금공단 | 노령연금(개시전, 현재가치 0%) | `national` | 65~90세 | 850,759 |
| 3 | 삼성증권 | 국고01500-5003(20-2) 외 | `db` | 61~80세 (20년) | 185,140 |
| 4 | 삼성생명보험 | 이율보증형(5년) 외 44건 | `guaranteed` | 55~74세 | 496,680 |
| 5 | 삼성생명보험 | 個노후적립연금보험 | `nohup` | 55~74세 (20년) | 276,115 |
| 6 | 삼성생명보험 | 인덱스Up변액연금1.0無2종적립 | `indexUp` | 65~90세 | 305,832 |
| 7 | 삼성생명보험 | 우리아이변액연금1.4無_2종적립 (1) | `ourChild1` | 60~90세 | 165,608 |
| 8 | 삼성생명보험 | 스마트Top변액연금無_2종 | `smartTop` | 65~90세 | 366,658 |
| 9 | 삼성생명보험 | 우리아이변액연금1.4無_2종적립 (2) | `ourChild2` | 60~90세 (31년) | 158,028 |

> 앱 분류 기준 변경: `guaranteed`(이율보증형)은 퇴직연금 DB 운용상품으로 재분류한다. `ourChild1`, `ourChild2`는 자녀 양도 예정이므로 원천 엑셀 합계에는 남기되, 본인 은퇴 현금흐름 합계에서는 제외하고 `childTransfer`로 별도 표기한다.
| 10 | 삼성생명보험 | 연금저축골드연금보험1.0(일반용) | `savings` | 56~90세 | 83,207 |
| 11 | — | 합 계 | `total` | 55~90세 | 2,888,027 |

> **인덱스 규칙**: 배열 인덱스 0 = 55세, 인덱스 35 = 90세  
> `ages[i] = 55 + i` (총 36개)

## 5. 데이터 변환 규칙

```js
// pensionData.js 값 → 화면 표시값 변환 파이프라인

// 1) 월 수령액 (천원/월)
const monthly_cheonwon = annual_cheonwon / 12

// 2) 화면 표시 (만원)
// 1,000원 = 0.1만원  →  천원 × 0.1 = 만원
const display_manwon = annual_cheonwon / 10 / 12   // 연간 천원 → 월 만원
// 예: 99,405 / 10 / 12 = 828.4 → "828만원/월"

// 3) 차트 데이터 (Recharts dataKey 단위)
// ComposedChart는 만원 단위로 넘기고 YAxis tickFormatter에서 "만" 붙임
const chartValue = Math.round(annual / 10 / 12)

// 4) 누적 막대 차트용 namedByAge 변환 예시
export function getCashFlowByAge() {
  return AGES.map((age, i) => ({
    age,
    national:  Math.round(national[i]  / 10 / 12),
    db:        Math.round(db[i]        / 10 / 12),
    savings:   Math.round(savings[i]   / 10 / 12),
    guaranteed:Math.round(guaranteed[i]/ 10 / 12),
    nohup:     Math.round(nohup[i]     / 10 / 12),
    indexUp:   Math.round(indexUp[i]   / 10 / 12),
    ourChild1: Math.round(ourChild1[i] / 10 / 12),
    smartTop:  Math.round(smartTop[i]  / 10 / 12),
    ourChild2: Math.round(ourChild2[i] / 10 / 12),
    total:     Math.round(total[i]     / 10 / 12),
  }))
}
```
