# 화면 스펙 — Wireframe & Design System

> 기준 뷰포트: **1440 × 900px** | No Scroll | shadcn/ui + Recharts  
> 레이아웃 원칙: 모든 화면은 스크롤 없이 단일 뷰포트 내 완결

---

## 0. 글로벌 레이아웃 시스템

### 높이 분배

```
┌──────────────────────────────────────────────── 900px ─┐
│ HEADER          56px  (로고 + 기준일)                   │
│ TAB NAV         44px  (5개 탭)                          │
│ ─────────────────────────────────────────────────────  │
│ CONTENT AREA   800px  (각 화면의 실제 렌더링 영역)       │
└────────────────────────────────────────────────────────┘
```

### 그리드 시스템

```
전체 너비: 1440px
좌우 패딩: px-8 (32px × 2)
사용 가능: 1376px

컬럼 구성:
  - 2분할: 460px | 16px gap | 900px
  - 3분할: 420px | 420px | 420px (gap 16px)
  - 4분할: 320px | 320px | 320px | 320px (gap 16px)
```

### 컴포넌트 규칙

| 요소 | shadcn 컴포넌트 | 비고 |
|------|------|------|
| 탭 네비게이션 | `Tabs` / `TabsList` / `TabsTrigger` | 상단 고정 |
| 섹션 컨테이너 | `Card` / `CardHeader` / `CardContent` | 패딩 p-4 |
| KPI 수치 카드 | `Card` + 커스텀 | 고정 높이 96px |
| 입력 필드 | `Input` + `Label` | |
| 드롭다운 | `Select` | |
| 슬라이더 | `Slider` | 건보료 화면 |
| 구분 배지 | `Badge` (variant) | 세제구분 색상 |
| 버튼 | `Button` (default/outline) | |
| 구분선 | `Separator` | |
| 툴팁 | `Tooltip` | 수치 설명 |
| 데이터 테이블 | `Table` | 시나리오 비교 |

### 색상 시스템 (Chart Colors)

```
국민연금      #3B82F6  (blue-500)      ← 공적연금
DB 퇴직연금   #10B981  (emerald-500)   ← 세제적격
IRP           #8B5CF6  (violet-500)    ← 세제적격
연금저축      #F59E0B  (amber-500)     ← 세제적격
세제비적격    #94A3B8  (slate-400)     ← 비과세
임대소득      #06B6D4  (cyan-500)      ← 기타소득
세금/건보료   #F87171  (red-400)       ← 차감 표시
```

### Badge 변형

```
세제적격   → variant="default"   bg: blue-100   text: blue-700
세제비적격  → variant="secondary" bg: slate-100  text: slate-700
공적연금   → variant="outline"   border: blue   text: blue
비과세     → variant="secondary" bg: green-100  text: green-700
```
